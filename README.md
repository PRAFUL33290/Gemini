# Google Gemini 3.5 - Site Vitrine

Ce projet contient une page vitrine de démonstration interactive de haut standing conçue en HTML5 et CSS3 modernes décrivant les innovations de **Google Gemini 3.5**.

## Fonctionnalités du site

- **Design Premium & Futuriste** : Effets de Glassmorphism, animations fluides, lueurs néon immersives et palette de couleurs rappelant l'univers Gemini de Google AI.
- **Démonstrateur Interactif (Playground)** : Console de simulation interactive en JavaScript natif permettant d'expérimenter des scénarios d'intelligence multimodale (flux vidéo drone, agent de codage de 2.5M de tokens, équations complexes).
- **Routage Mixture of Experts (MoE) Dynamique** : Schéma d'architecture animé reflétant en direct le routage des requêtes utilisateurs vers les modèles experts (vitesse, code, maths).
- **Responsive & Fluide** : Entièrement compatible avec les tablettes, smartphones et grands écrans d'ordinateurs.

## Structure des fichiers

- `index.html` : Structure sémantique de la page avec la console interactive JavaScript.
- `style.css` : Design, grille CSS Grid/Flexbox, animations clés en main et styles réactifs.

## Comment visualiser

Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur web moderne.
